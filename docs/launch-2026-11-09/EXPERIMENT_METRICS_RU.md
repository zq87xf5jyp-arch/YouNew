# Метрики эксперимента: значения не собраны

Состояние 9 ноября 2026. Публикации и кампания не запускались. Новый production tracking не включался. Значения ниже неизвестны, а не равны нулю. Существующий Hostinger analytics cron не менялся.

| Сигнал | Минимальное значение | Исходное значение | Ограничение |
| --- | --- | --- | --- |
| Переход из канала | Код канала/поста, агрегированное число кликов | Нет данных | Клик не равен человеку; метрика доступна не каждому аккаунту |
| Поиск | Счётчик, язык, ограниченное число результатов | Нет данных | Без текста запроса; один подтверждённый поиск, не каждый ввод символа |
| Поиск без результатов | Подмножество поисков с resultCount=0 | Нет данных | Не складывать с общим числом поисков как отдельные поиски |
| Открытие карточки | Счётчик действия, язык | Нет данных | Не считать и click, и resulting page view одной конверсией |
| Официальный сайт | Счётчик активаций ссылки, язык | Нет данных | Это переход, не подтверждение посещения организации |
| Маршрут | Счётчик активаций ссылки, язык | Нет данных | Не собирать геопозицию пользователя |
| Начало BUSINESS | Первое изменение формы за попытку | Нет данных | Повторный input не новое начало |
| BUSINESS сохранён | Один валидный server receipt | Нет данных | Валидация, timeout, mailto и повтор того же receipt не успех |
| Реальные пользователи | Подтверждённая отдельным методом оценка | Не измерено | События, сессии и просмотры не доказывают 100 уникальных людей |

Существующий канонический транспорт `admin-dashboard/public-site/src/lib/analytics/client.ts` ограничивает передаваемые свойства: тексты запросов, контакты и подробные фильтры не входят в payload. Он использует session/app identifiers и согласие; это не тождественно отдельному локальному прототипу без идентификаторов. Его текущие условия нельзя автоматически менять ради эксперимента.

Уникальный ранний прототип сохранён в `preserved-leiden/local-experiment.original.ts`. Он допускает только localhost/127.0.0.1 и явный sessionStorage opt-in, хранит максимум 300 строк в памяти и не отправляет запросов. В канонический UI он пока не подключён. До интеграции надо подтвердить поведение EN/NL, однократность search/card/form событий, отсутствие успешного submit при mailto/ошибках и отсутствие передачи приватных полей. Отсутствие такой проверки не маскируется нулевой конверсией.

Собственные проверки записываются только как environment=test и не входят в отчёт привлечения. Трафик известных ботов не считается посетителями; при невозможности надёжно отделить его показатель остаётся смешанным и не объявляется числом людей. Без отдельного включения новой аналитики оценка полезных действий недоступна; можно фиксировать лишь уже доступные агрегированные показатели платформ. Новые сервисы не нужны.
