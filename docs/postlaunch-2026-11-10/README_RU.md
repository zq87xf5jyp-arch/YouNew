# YouNew: оставшиеся задачи после запуска

## Email

На Hostinger включены уведомления для **support@younew.nl** о новых доставленных
BUSINESS-заявках и изменениях состояния сайта. В письме только количество и ссылка
на Admin; контакты и текст заявок не читаются worker и не отправляются.

Существующая почта Standard Business Email действует до 20 июля 2027. Использован
встроенный PHP mail Hostinger: новая услуга, подписка, SMTP-пароль или DNS не нужны.
24 попытки отправки за скользящие сутки, один дайджест за запуск, повторы с задержкой.
Исторические четыре заявки внесены в baseline и не рассылаются повторно.

Проверено: 22 вызова интеграционных сценариев локально и ещё 22 в изолированном
Hostinger QA; реальное QA-письмо получено в INBOX в 21:43:23 по Амстердаму.
Production cron `*/5 * * * *` выполнился **10 ноября в 21:50:01**, его отдельное
письмо найдено в INBOX в 21:50:23. Ручной запуск не выдан за работу cron.

Файлы: `/domains/younew.nl/younew-private/notifications/`; код worker соответствует
commit `a7e38507ef9c29c67c00fb63857dfce09fdf57b8`. Команда cron:

```text
/bin/bash /home/u246392949/domains/younew.nl/younew-private/notifications/run.sh
```

Монитор сайта по прежнему расписанию */15 теперь отражает включённый email-канал
в конфигурации. Его сетевые проверки не менялись; обе конфигурации флага проверены
на QA. При полном отказе Hostinger этот же сервер не сможет отправить письмо:
независимый внешний мониторинг не заявляется. PHP mail подтверждает приём локальным
почтовым сервером, не каждую конечную доставку; проверочные письма получены фактически.

SMS не включены: оплаченного или включённого канала отправки не подтверждено.
Новый платный SMS-провайдер, пробная подписка и расходование кредитов не подключались.
