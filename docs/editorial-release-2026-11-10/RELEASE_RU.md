# Публикация одобренной партии EN/NL

Владелец одобрил конкретные 71 материал (54 места, 10 LIVE-гидов, 5 подборок, 2 BUSINESS-текста), SHA-256 `4010ebb033f399c0807bd2dca43b66c8ae03ba4ac0cfdc0e632fe718ee6293ea`. Исходные 10 файлов не изменены. Неизвестные поля пусты, фотографии не добавляются. Три точки имеют подтверждённые координаты; остальные остаются в списке.

Добавлены 142 страницы EN/NL и входные страницы `/leiden/`, `/nl/leiden/`. Поиск учитывает местные гиды и голландские заголовки. Краткие одобренные гиды выделены в отдельный формат; они не объявляются полными PracticalGuide v2. Существующие проверки полных гидов и ограничения на публикацию других черновиков сохранены.

Admin различает редакторское одобрение и состоявшуюся публикацию. Статус меняется только после проверенного выхода сайта, по закрытой записи, связанной с SHA партии, содержимым каталога и commit. Права пользователей, реальные заявки и база не изменяются.

Локально: 243 unit-проверки сайта; 2608 поисковых сценариев; 608 sitemap URL; 36 485 внутренних ссылок; TypeScript, ESLint, smoke, security и runtime 404 — PASS. Проверка источников и готовности учитывает 71 дополнительную запись отдельно от 454 исходных governed records. 97 Python contract tests и два теста защиты статуса публикации — PASS.

Публикация выполняется через `hostinger/editorial/release.py` и `node-release.py`: изолированный Hostinger QA, проверка каждого EN/NL HTML по SHA, пробный откат, отдельная резервная копия, атомарная замена только кода, проверка production, затем запись факта публикации. Данные, DNS, почта и cron не заменяются. Новые расходы отсутствуют.

Фактические результаты Hostinger и CI добавляются после выполнения; этот документ сам по себе не подтверждает активацию production.
