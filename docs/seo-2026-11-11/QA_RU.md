## Практические пределы

Не заявлены: индексация Google, трафик, реальные установки, все внешние ссылки сайта, полевые LCP/INP/CLS, редакторский допуск шести гидов или выполненные будущие 90 дней. Отчёт PHP выдаёт дневную медиану времени; недельную нельзя получать усреднением медиан. Возврат измеряется в когорте согласованных визитов на полные гиды, не уникальных людей. Изменение этой области измерения требует обновления определения перед включением.

Доступ к GSC/Apple, человеческая проверка EN/NL и медиа, свежая проверка изменчивых фактов и отдельный выпуск остаются необходимыми следующими шагами. Новые рассылки/обращения не отправлялись.

`review-index-final.png` — финальная оформленная страница проверки r4. Её CSS-подключение проверено отдельно; содержимое 12 гидов r3/r4 идентично.

## Исправление инфраструктуры Admin CI

Задание Admin в run `43039791747` дважды остановилось до браузерной матрицы: APT не разрешал `azure.archive.ubuntu.com`. Повтор на официальных HTTPS-зеркалах также показал ошибку DNS для `archive.ubuntu.com` в run `43044409281` (живой лог).

Итоговая конфигурация использует официальный Microsoft Playwright `v1.55.1-noble`, совпадающий с `@playwright/test` в lockfile, закреплённый по SHA-256 `2f29369043d81d6d69a815ceb80760f55e85f5020371ad06a4d996f18503ad1c`. Образ уже содержит браузеры и системные библиотеки; APT во время задания не используется. Node 24 и Python 3.12 устанавливаются существующими закреплёнными Actions. Перед полной неизменённой матрицей проверяются версия библиотеки и наличие исполняемого Chromium. Образ используется только для локального синтетического приложения CI, не для production или внешних сайтов. Промежуточное изменение APT удалено.

Первичные источники: [Playwright Docker](https://playwright.dev/docs/docker), [официальный manifest MCR](https://mcr.microsoft.com/v2/playwright/manifests/v1.55.1-noble). Ответ manifest сохранён в локальном evidence; его SHA-256 совпал с заголовком реестра. Настройки Hostinger и компьютера владельца не меняются.
