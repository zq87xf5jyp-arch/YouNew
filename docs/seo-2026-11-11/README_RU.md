Новое согласие, публичный allowlist ID, одна конверсия на гид/локаль/сессию вкладки/UTC-день, активное время, локальная дата предыдущего визита. Постоянный междневной идентификатор не добавлен. Поисковые фразы, документы, email и полный referrer не передаются.
- 50 запросов, 13 недель/120 часов, 10 метрик, девять последующих заданий, шесть адресных EN/NL-черновиков обращений и генератор еженедельного отчёта. Рассылка, DE/ES и обращения остаются отложенными.

## Еженедельный процесс

Обновить `WEEKLY_INPUT.json` реальными агрегатами и границами периода, сохранив часовой пояс каждой системы. Не подставлять нули за отсутствующие данные. Затем:

```sh
python3 scripts/seo/weekly-report.py --input docs/seo-2026-11-11/WEEKLY_INPUT.json --output docs/seo-2026-11-11/WEEKLY_BASELINE.md
```

При выборке менее 100 подходящих сессий отчёт показывает абсолютные значения и скрывает неустойчивые процентные оценки/медиану. Медианы по дням нельзя усреднять в недельную медиану: для неё нужен расчёт по исходной выборке на сервере. В текущем варианте сервер предоставляет дневные медианы; недельное значение оставляется N/A без отдельной агрегации.

Каждый понедельник: источники и ошибки → поиск 7/28 дней → официальные действия/сохранения → доступные возвраты/приложение → одна страница для улучшения и одно решение. Автоматическая рассылка отчёта и новая автоматизация не созданы.
