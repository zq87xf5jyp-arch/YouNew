# Решения спринта

## U001 · 15.11.2026 · Развивать существующую главную

Проблема: нужные для открытия города категории скрыты за несколькими большими
блоками. У сайта уже есть hero, лицензированные фото городов, поиск и категории.
Решение: компактная навигация из существующего массива категорий прямо под поиском,
без нового client component, запроса к API, библиотеки, фотографий или рейтингов.
Local services направляется в существующую наполненную категорию, не пустой тип organization.
Нейтральная подпись Practical tasks заменяет недоказанное Popular tasks.

Ссылки в compact и полном блоке используют один источник данных; это два входа в
одни страницы, не два каталога. Четыре направления соответствуют опубликованному
содержимому. Не обещать hotels, tickets, availability или curated tours сверх данных.

## U002 · Отдельная ветка от main

Г01/SEO PR59 требует собственного review. Новый спринт не должен незаметно включить
его production-изменения. Ветка от current main содержит только текущий небольшой UI
шаг и карту проекта. Существующая работа и неизменяемое защищённое QA сохраняются.

## U003 · Доказательства и источники

Прямой live HTTP сильнее старой поисковой копии. Дата аудита UI не становится датой
проверки фактов. Статусы EXISTS/PARTIAL не заменяются VERIFIED только из-за зелёного CI.
403/429 стороннего сайта фиксируются как ограничение доступа.

## U004 · Единая документация без второй архитектуры

Этот каталог индексирует существующие release/SEO/операционные документы, а не копирует
миграции, схемы и исторические отчёты. Современная карта разделяет web, iOS, content,
Admin и hosting. Будущие спринты читают историю и проверяют только изменившиеся условия.

## U005 · Повторно использовать готовое исправление CI

В новую ветку перенесён только `.github/workflows/admin-ci.yml` из проверенного
head PR59 `47813e7`: официальный Playwright 1.55.1 container с закреплённым SHA,
Python и доверие только к `$GITHUB_WORKSPACE`. Это готовое исправление APT/DNS,
а не новая реализация. Полная ролевая матрица Admin сохранена, тесты не пропускаются.
Другие изменения PR59 не включены. Workflow не добавляет production-зависимости.
